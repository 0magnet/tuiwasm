All 45 demos

tuiwasm runs Go's terminal-UI libraries — tcell for the screen layer, and the Charm stack above it: lipgloss for styling, bubbletea for the update loop, glamour for Markdown — inside a browser tab, drawing into a real terminal emulator built on xterm-go. Every demo below is the same WebAssembly binary with a different query string; each link opens it running.
