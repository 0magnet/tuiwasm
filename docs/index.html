tuiwasm — Go terminal UI libraries in the browser

The Go terminal-UI ecosystem, compiled to WebAssembly and running in a browser tab on top of xterm-go: tcell for the screen layer, and the Charm libraries — lipgloss for styling, bubbletea for the update loop, glamour for Markdown rendering — drawing into a real terminal emulator in the page.

A launcher offers dozens of demos and terminal animations: Conway's Life, Langton's ant, a Julia set, boids, physarum, reaction-diffusion, plasma, fire, matrix rain, a rotating cube, a spinning donut, mazes, metaballs, starfields, Wolfram cellular automata, plus widget, table, style and truecolor showcases.

Source code: github.com/0magnet/tuiwasm. More Go and WebAssembly projects: magnetosphere.net/software.
